# Contributing

Thanks for helping CookieTrim handle consent banners more safely.

1. Open an issue describing the website, language, visible button labels, and expected safe action.
2. Do not include account data, cookie values, tokens, or private page content.
3. Keep selectors narrow and prefer explicit reject or necessary-only controls.
4. Never add behavior that clicks an accept-all control or hides a banner without recording consent.
5. Add or update tests, then run `npm test` before opening a pull request.
